# Official reference artwork

Public source: https://endfield.hypergryph.com/ . Exact source URLs and SHA256 hashes
are in `sources.json`. Original artwork rights remain with the game rights holders.

Used with the user's explicit request to reuse official imagery: Perlica and
Endministrator full-size collages, terrain patterns and section divider illustration.
Point and wave textures are available supporting artwork.

The original CSS/JavaScript are reference evidence, not executed in this app.
Motion uses local CSS and the existing Framer Motion dependency. The character
images are static artwork animated by masks and scrolling; this does not import
the official video/WebGL animation.
