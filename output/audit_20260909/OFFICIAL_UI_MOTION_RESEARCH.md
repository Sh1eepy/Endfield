# 终末地官网界面与动效研究（2026-09-09）

## 结论

官网可以访问，没有被目标站点封禁。最初的 `stream disconnected` 与内置动态浏览器超时属于当前工具链的传输/渲染连接问题。切换到沙箱外直连后，首页返回 `200 OK`；响应表明页面使用 Next.js，静态资源来自 `web.hycdn.cn`，边缘服务为 Tencent EdgeOne。随后用本机 Edge 无头模式完成了首页、新闻页、云游戏页和官方社媒活动页的真实渲染截图。

本项目适合复用官网的“运动语法”和信息层级，不适合把宣传站的全屏视频与下载入口直接搬进查询工具。此次实现只使用项目自己的数据与本地素材，没有拷贝官网图片、脚本或样式文件进产品代码。

## 证据等级

- **A / 直接渲染**：Edge 实际加载公开 URL 后生成的 1440×900 截图。
- **B / 直接资源**：从当前页面 HTML 引用地址下载的公开 CSS/JS；可验证动画时长、缓动、遮罩和页面结构。
- **C / 搜索索引**：用于发现子页和确认新闻详情路径，不用于推断视觉细节。
- **D / 旧本地存档**：仅用于交叉核对，不作为本轮主要证据。

## 页面观察

### 首页 `https://endfield.hypergryph.com/`

- 约 68px 的固定左侧导航轨贯穿视口，品牌位于顶部，图标按钮按区块排列，下载入口在底部。
- 首屏使用全幅版本主视觉，界面控件集中在边缘；下载面板为半透明黑色块，强调色为高亮黄。
- 页面资源中存在全屏滚动查看器、1.6 秒循环滚动提示、分区命名的 Gameplay / AIC / Calendar 样式，以及渐变遮罩与裁切。
- 当前首页为 Next.js 服务端输出，HTML 同时提供新闻与版本视频数据；视觉主层由客户端脚本接管。

### 新闻页 `https://endfield.hypergryph.com/news`

- 延续固定左轨，但内容区转为大面积白底，顶部留白很大。
- 标题区由横向黄色色带、黑色粗体标题、机械插画组成；正文使用三列卡片网格。
- 标签页和新闻卡片依靠 0.2–0.3 秒颜色/位移反馈，页面没有首页那种持续高强度运动。

### 云游戏页 `https://endfield.hypergryph.com/cloud`

- 黄色与白色作为大面积底色，角色拼贴与超大浅色英文字形成前后景。
- 中央 CTA、三角构图、线路与网格共同指向主操作。
- 当前 CSS 资源包含 70 组 keyframes、130 处动画声明、26 处 clip-path；大量动画为 0.25–1.5 秒的分层进场，环境层含约 40 秒的慢漂移。

### 官方社媒页 `https://endfield.hypergryph.com/activity/social-media`

- 左侧角色大图，右侧为标题与 2×3 社媒卡片；60/120/180 奖励节点形成纵向进度线。
- 卡片默认为灰度块，高亮信息使用黄色；页面底部以整条黄色区域收束。
- 交互动效集中在 0.2–0.5 秒，宽高、背景和遮罩变化短促直接。

## 可复用的动效规则

1. **遮罩先于透明度**：区块进场以 `clip-path: inset(...)` 或 polygon 横向展开为主，透明度只辅助，不使用大面积模糊。
2. **交互短、环境慢**：按钮和卡片 0.2–0.4 秒；区块进场约 0.5–0.8 秒；只有背景纹理使用 9–40 秒循环。
3. **单向运动**：按钮高亮从同一方向扫入，列表由左向右依次出现；避免弹簧回弹和随机漂浮。
4. **黑白承载，黄色指路**：黄色只承担当前状态、入口和关键数据，不把每张卡片都做成高饱和色块。
5. **固定轨道建立空间感**：桌面左轨不随内容跳动；移动端折回为紧凑顶栏。
6. **持续动画不承担功能**：查询、滚动与结果阅读在关闭动画或 `prefers-reduced-motion` 下保持完整。

## 已映射到本项目的第一轮改造

- 桌面端顶栏改为固定左轨，查询和结果区有真实锚点；850px 以下恢复横向顶栏。
- 主色收敛为冷白、炭黑和高亮黄；隐藏抢视线的背景吉祥物，保留更轻的工程网格。
- Hero 标题改为逐行遮罩揭示，右侧数据块改用官网式黄黑结构与信号条。
- 搜索框增加单向顶边扫描，联想列表使用短促阶梯入场。
- 结果区进场从模糊漂浮改为 clip-path 裁切；面板只保留一条低强度扫描线。
- 开场由 3.4 秒缩短到 1.25 秒，仅每个会话首次播放；增加 2 秒硬超时，后台标签暂停 `requestAnimationFrame` 时也不会挡住页面。
- 保留完整 `prefers-reduced-motion` 降级。
