# 微信小程序端

这个目录是网页端的移动入口，复用同一个 FastAPI、配方数据、RAG 和知识图谱，不在小程序里保存模型或 API Key。

## 已有功能

- 配方制造与知识问答使用独立查询词；首次进入均为空；
- 名称联想、本地搜索历史和后端连接状态；
- 可拖动、缩放和折叠的纵向 Canvas 合成树；
- 知识问答、引用来源、检索片段和结构化配方结果；
- 干员档案、富文本表格、图片、语音和外部视频入口；
- 机械开场动画与统一工业档案视觉。

## 开发者工具运行

先在项目根目录启动单进程后端：

```powershell
$env:WEB_CONCURRENCY = "1"
python scripts/start_server.py
```

然后打开微信开发者工具，选择“导入项目”，项目目录指向本目录。模拟器默认请求
`http://127.0.0.1:8000`，公共配置在 `project.config.json`。

## 真机调试

手机里的 `127.0.0.1` 是手机本身，不能访问电脑后端。调试前：

1. 查询电脑局域网 IP，例如 `192.168.1.20`；
2. 把 `app.js` 的 `apiBase` 临时改成 `http://192.168.1.20:8000`；
3. 确认后端监听 `0.0.0.0`，手机和电脑连接同一网络；
4. 在开发者工具调试阶段关闭合法域名校验，并按需允许 Windows 防火墙端口。

调试后不要把个人机器 IP 提交到仓库。

## 正式发布

小程序正式版只能连接已配置的 HTTPS 服务。发布前应：

1. 部署后端并确认 `/api/health` 返回正常；
2. 把 `app.js` 的 `apiBase` 改成线上 HTTPS 域名；
3. 在微信公众平台配置 request 合法域名；
4. 真机检查名称联想、配方树、RAG 回答、引用、图片和语音；
5. 确认 `.env` 和任何 API Key 都只存在于后端。

`project.private.config.json` 是个人开发者工具设置，已被 `.gitignore` 排除；`project.config.json` 是团队公共配置，继续提交。
