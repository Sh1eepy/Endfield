# Web 视觉细化验收 · 2026-09-13

## 当前实现

- 入场末段和首页叠加官网横版宣传主视觉，使用去色、透明度及渐变遮罩；首页和共享空间的等高线改用深色源图反相增强。
- 首页五位角色手动切换：佩丽卡、管理员、莱万汀、陈千语、艾尔黛拉。来源和哈希见 [素材说明](ASSETS.md)。
- 标题使用本地 Noto Sans SC，英文标识与数字使用 Oxanium，正文优先系统中文 UI 字体；正文 16px、表格 14px，多数辅助文字提高至 11–13px。手机首页增加纵向空间容纳五个角色按钮。
- 干员信息、技能表和物品结构表采用黄灰底色、细边框、交替行底色和一致滚动条，保留源数据中的强调色与全部内容。
- 三环共享指针及页面滚动产生的微移/倾斜，每环额外使用不同频率和幅度的轻微摆动，基本保持平行。
- 档案盒沿高度错相波动，径向幅度 0.32、纵向幅度 0.22 世界单位；骨架和横向连接线同步更新，仍为无业务绑定的展示载体。

## 验证证据

- `npm test`：42/42；`python -m unittest tests.test_frontend_contract -v`：10/10；`npm run build` 通过。构建仍有既有 Three.js 分块超过 500 kB 的提示。
- 按 [测试矩阵](TESTING.md) 运行现有 `check_spatial_frontend.mjs`；证据保存在本地生成目录 `output/frontend-polish/`，不提交图片及报告。
- 1440×900、390×844 均无页面横向溢出，无 pageerror；两种视口、三种指针方向下拾取成功，抽出/收回误差为 0，收回后恢复 56 个载体。
- 阅读时渲染暂停；WebGL 上下文丢失后移除 canvas，减少动画模式 canvas 数为 0；手机触摸指针不改变空间指向，命中区域保持 `pan-y`。
- 内置浏览器连接真实后端，检查莱万汀详情、能力扩延、属性与精英化材料表，以及协议圆盘的知识库来源/用途卡；修复深色头卡与旧文字颜色冲突。手机首页人工检查并修复切换按钮与入口重叠。

## 边界

空间脚本使用模拟查询响应；真实后端检查限于上述直查样例，未评估在线 LLM 回答质量。手机为浏览器视口/触摸模拟，未做 Android/iOS 真机或 GPU 长时间功耗测试。素材仅作展示，不修改知识库、图谱、配方及接口契约。
