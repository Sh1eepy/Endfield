## 最近完成的改进

- 2026-09-13 Web 视觉细化：入场与首页增加淡化官方宣传图、五位角色切换、分层字号与黄灰档案表格；中央三环增加指针/滚动响应与不同频率微摆，载体与骨架共用连续波形。42 项前端测试、10 项契约测试、构建及桌面/手机空间验收通过，见 [视觉细化验收](FRONTEND_POLISH_ACCEPTANCE.md)。

- 2026-09-12 Web 空间升级：6 秒分段开场、Home/Query 共享双螺旋、滚动衔接、查询进度反馈、薄型抗锯齿玻璃载体、中央环及指针/页面滚动圆弧运动。42 项前端测试、10 项契约测试、生产构建通过；两个视口浏览器证据与未验证边界见 [空间升级验收](FRONTEND_SPATIAL_ACCEPTANCE.md)。

- 2026-09-11 Web 新增双模式空间入口：按需 Three.js 玻璃装置、镜头切换、静态降级与模式说明；32 项前端测试、10 项结构契约测试及构建通过。桌面/手机已检查，真实后端联调与 GPU 功耗对比未完成，详见 [实现与边界](FRONTEND_EXPERIENCE.md)。

- 修复实体解析优先短名称的问题，完整名称优先且来源保留真实 `item_id`；
- 名称规范化、分词与向量 ID 映射改为加载时预计算，去除重复子查询和无条件重复检索；同机 warm 离线探针从约 796–813 ms 降至约 24–25 ms，线上 LLM 延迟不在该结论内；
- 增量 RAG 使用新旧 chunk 全集差分，删除条目缩短后的遗留向量；模型变化强制隔离输出目录；BM25 与 manifest 原子发布并最终审计；
- GraphRAG 指纹覆盖结构化章节、干员详情和规则 schema；实体 UPSERT，运行时只读打开 SQLite，单来源路径可追溯；
- 流式模型响应必须有明确完成原因；首字前可重试，输出开始后不重试；截断最多续写一次并共享单次 LLM 操作总预算；
- 流式准入推迟到 ASGI 响应开始，修复未消费响应导致的并发名额泄漏；代码版本、配方索引和 KB 名称位置按进程缓存；
- Web 模式切换不再自动发问，支持停止生成，首 token 不再等待面板重挂载，Markdown 在流结束后一次解析；
- 小程序修复干员语音来源、引用表格、KB link/行内媒体，并将整包问答超时调整为 180 秒；
- 媒体代理拒绝 SVG、HTML 与未知 MIME，保留域名、路径、大小、超时、重定向和并发限制；CORS 改为显式白名单；
- Web 改用官网视觉与运动语法：固定左轨、黄黑信息层、单向遮罩、每会话一次的 1.25 秒开场和 2 秒硬超时；小程序同步视觉并移除首页阻塞式开场。

## 质量快照

- 71 条整改后严格检索快照：Recall@5 100%、MRR 98.36%、Precision@5 45.35%；
- 25 条离线路由集：route accuracy 92%；
- 图固定集 10/10；关系正向、反向和是非问审查 1,656/1,656；
- 答案黄金集仅 6 条，不能用于声称生产回答准确率；
- 两份历史评测缺少当前 manifest 元数据，普通门禁仅警告，严格发布门禁会拒绝。
