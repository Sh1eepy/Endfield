# 素材、数据与免责声明

本文是项目唯一的来源追溯与合规说明。产品使用的每一类内容——美术素材、字体、知识数据、第三方代码和生成物——都在这里记录来源、性质和使用边界。新增任何素材或数据源之前，先读本文并在对应小节补一行。

## 一、内容分类与法律性质

项目里的内容按性质分三类，使用边界不同：

| 类别 | 法律性质 | 项目中的例子 | 处理方式 |
|---|---|---|---|
| **事实与数值** | 通常不受著作权保护 | 配方、材料数量、设备参数、物品名称 | 自由整理与再分发；仅用于查询 |
| **作品（表达）** | 受著作权保护 | 角色立绘、宣传主视觉、游戏徽标、字体文件 | 记录来源、保持署名、非商业使用 |
| **第三方代码** | 各自许可（MIT / OFL 等） | Three.js 缓冲阻尼算法、开源字体 | 保留许可文本与声明 |

**项目不收录的内容**：游戏音乐与音效、过场影像、完整剧情文本、官网整站镜像、浏览器缓存、无法说明来源的文件。产品界面没有音频播放功能。

## 十、技术选型

- **素材本地化**：官网图片下载到 `web/assets/official/`，由 `sources.json` 记录来源 URL、字节数与 SHA256；运行期不依赖官网 CDN，也不执行官网 JavaScript；
- **动效与 3D 自研**：CSS 与 Framer Motion 负责 DOM，Three.js 负责中性空间层；不引入官网视频或第三方品牌模型；
- **小程序轻量化**：只复制实际使用的素材，因为微信对主包与分包体积有硬上限；
- **素材与业务解耦**：素材缺失只影响视觉，不影响配方、检索或问答结果，页面必须有兜底样式；
- **数据只读上游**：事实源与既有历史导出物只读，采集与解析脚本不修改上游数据。

## 十一、常见问题与对策

| 问题 | 对策 |
|---|---|
| 素材来源无法追溯 | `fetch_official_design_assets.py` 记录 URL、大小与 SHA256 到 `sources.json`；吉祥物图待补记录 |
| 小程序包体超限 | 只保留实际使用素材；发布前检查包体积 |
| 版权与署名遗漏 | README、页脚保留"非官方社区工具"说明与权利归属提示 |
| 图片加载失败出现空白 | 图片 `onError` 兜底隐藏或占位；媒体代理失败返回明确状态 |
| 抓取整站或浏览器缓存入库 | 只下载选定公开图片，缓存与整站快照不入版本库 |
| 3D 展示混入第三方品牌 | 只使用程序化中性几何；RhineLabUI 仅保留 MIT 阻尼算法声明 |
| 权利方提出异议 | 按第七节第 7 条立即下架相关内容并记录处理过程 |
