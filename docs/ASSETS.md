# 素材来源与使用

Web 的官方参考素材位于 `web/assets/official/`，完整来源 URL、字节数和 SHA256 保存在 `web/assets/official/sources.json`。当前首页可切换佩丽卡、管理员、莱万汀、陈千语和艾尔黛拉；入场和首页使用官网横版宣传主视觉 `talos-keyvisual.jpg`，通过 CSS 去色、渐变遮罩和透明度淡化，原图不修改。等高线使用已有 `home-background.jpg` 反相增强。小程序仅复制原先实际使用的三份素材以控制包体，本次新增素材不进入小程序。

公开来源为《明日方舟：终末地》官网 `https://endfield.hypergryph.com/`。相关名称、图像和内容权利归原权利方所有，页面应保持“非官方社区工具”说明。

`scripts/fetch_official_design_assets.py` 只下载选定公开图片，不执行官网 JavaScript。官网 CSS/JavaScript 和审查期页面快照仅作设计证据，不进入产品运行链路。

界面运动由项目自己的 CSS、Framer Motion 与 Three.js 实现。角色图片仍是本地静态素材；3D 双螺旋、档案盒和环均由程序化几何生成，并非官网或 RhineLabUI 模型。项目没有导入官网视频、Rhine 品牌标识、档案数据、字体、声音或 GLB；只复用清单中的终末地地景、纹理和波纹素材。详见 [Web 空间体验](FRONTEND_EXPERIENCE.md)。

新增素材时必须：记录来源、大小与 SHA256；确认产品确实使用；更新署名；检查 Web 构建与小程序包体；不提交浏览器缓存、整站抓取或无法说明来源的文件。

## 技术选型

- **素材本地化**：官网图片先下载到 `web/assets/official/`，由 `sources.json` 记录来源 URL、字节数和 SHA256；运行期不依赖官网 CDN，也不执行官网 JavaScript；
- **动效与 3D 自研**：CSS/Framer Motion 负责 DOM，Three.js 负责中性空间层；不引入官网视频或第三方品牌模型，素材权利仍按上方说明归原权利方所有；
- **小程序轻量化**：只复制实际使用的素材，因为微信对主包/分包体积有硬上限；
- **素材与业务解耦**：素材缺失只影响视觉，不影响配方、检索或问答结果，页面必须有兜底样式。

## 测试问题与对策

| 问题 | 对策 |
|---|---|
| 素材来源无法追溯 | `fetch_official_design_assets.py` 记录 URL、大小与 SHA256 到 `sources.json` |
| 小程序包体超限 | 只保留实际使用素材；发布前检查包体积 |
| 版权与署名遗漏 | README、页脚保留"非官方社区工具"说明与画师署名 |
| 图片加载失败出现空白 | 图片 `onError` 兜底隐藏或占位；媒体代理失败返回明确状态 |
| 抓取整站或浏览器缓存入库 | 只下载选定公开图片，缓存与整站快照不入版本库 |
| 3D 展示混入第三方品牌 | 只使用程序化中性几何；RhineLabUI 仅保留 MIT 阻尼算法声明 |

## 扩展准备

- 可在 CI 增加清单校验：比对 `sources.json` 与磁盘文件，发现缺失或哈希变化即失败；
- 若将来需要视频或循环动图，优先使用可本地托管的短素材，避免外链与自动播放；
- 角色立绘如扩展为多版本（异格/皮肤），必须逐项记录来源与授权说明，并同步小程序包体评估。
