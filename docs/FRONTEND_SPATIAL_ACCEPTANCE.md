# 空间升级与验收 · 2026-09-12

## 当前实现

### 同日小修正

- 页面原生上下滚动以每屏 0.22 rad 驱动缓慢旋转，沿用 TransitionCoordinator 平滑；不拦截触摸手势。阵列按钮/拖动浏览也带来小幅旋转。
- 删除「解析构成」「循着线索」后的中文句号。
- 内容展开时不显示「档案内容已就绪」，跳过抽取按钮在面板显现（extraction ≥ 0.64）后隐藏；静态与减少动态效果也隐藏该按钮。
- 42 项前端测试、10 项契约、构建通过。两视口浏览器复测中，从首页滚到查询区，yaw 分别由 0 → 0.26886、-0.01512 → 0.23874；展开后 readyHintAbsent / skipHidden 均为 true，抽取收回仍为 1 → 0。

- 开场主时间轴 6 秒，随后释放遮罩；8 秒安全超时。文字动作仍较快，扫描和欢迎画面增加停留。支持 Esc、跳过、重播、会话一次与减少动态效果。
- Home、200px 桌面 / 130px 手机过渡区和 Query 共享一个 sticky canvas。滚动进度驱动取景和纹理显露；角色与黄色色块在底部渐隐，不劫持页面滚动。
- 配方保持浅灰工业空间；知识问答使用石墨色与工业黄。复用既有官网地形、波纹及颗粒素材，没有新增外部资产或依赖。
- 档案玻璃主体改为 3.2 × 1.6 × 0.42，边框深度 0.46。共享几何增加圆角分段；EffectComposer 使用最高 4x MSAA 渲染目标，降低泛光以减少白边扩散。
- 56 个档案展示载体组成双螺旋。载体、骨架与连线使用同一连续波形；骨架改为可更新折线，避免每帧重建 TubeGeometry。
- 中段增加半径 6.4 的主金属环及两条辅环。环静止，螺旋在共同父级的中心旋转，构图偏移位于父级；指针映射 yaw ±0.58、pitch ±0.13 rad，复用原有 5/s 平滑。移除指针相机平移。
- 选中轮廓挂在载体本地坐标下；抽取锁定真实世界位置和旋转，收回接续载体的世界姿态。
- 查询后立即出现不确定进度条与已等待秒数，使用现有 phase_text，不编造完成百分比。SSE 阶段消息不会使等待反馈提前停止，保留停止按钮。
- 可见、未展开内容时阵列持续轻微运动；稳定阅读后停止渲染，滚动/尺寸/模式变化补画。离屏、后台、静态、上下文丢失和减少动态效果保留降级路径。不是完全零功耗，也没有声称降低固定百分比。
- 手机不响应触摸指针及阵列拖动，保留 pan-y，使用 ↑↓ 按钮浏览。桌面继续支持鼠标拖动和拾取。

## 实际浏览器证据

工具：现有 Playwright + 本机 Edge headless，真实 WebGL 渲染。使用 1440×900、390×844 两个视口。原始截图与 JSON 是可重建本地产物，不进入普通 Git 历史；下表保留本轮核对结果。

| 检查 | 1440×900 | 390×844 |
|---|---|---|
| canvas / 页面异常 / 横向溢出 | 1 / 0 / 无 | 1 / 0 / 无 |
| 查询等待条 | 可见 | 可见 |
| 页面抽取 → 收回 | 1.000 → 0.000 | 1.000 → 0.000 |
| 稳定阅读 600ms 内帧数变化 | 0 | 0 |
| 环在 -0.58 / 0 / +0.58 yaw 下投影边界 | 均在视口内 | 均在视口内 |
| 固定姿态抽取起点 / 收回起点误差 | 均为 0 | 均为 0 |
| 收回后可见载体 / 位置恢复误差 | 56 / 0 | 56 / 0 |
| WebGL 上下文丢失 | canvas 清理 | canvas 清理 |

浏览器内直接渲染场景，在三个角度对载体中心做 raycast：桌面每档 15/15/16 个中心正确命中自身，手机 36/33/34；不是所有中心都应命中自身，背面可能被前排遮挡。另在真实桌面 UI 通过鼠标点击确认选中编号改变，截图检查轮廓随盒子朝向贴合。

手机触摸事件前后 pointerX 均为 0，touch-action 为 pan-y；这是浏览器触摸仿真，不是 Android/iOS 真机手感验证。

验收脚本为每个视口保存首页、过渡区、左右旋转、等待、抽取、收回及降级截图；运行命令见文末，产物不作为运行依赖。

## 验证边界

- 查询动画验证使用浏览器拦截的延迟 SSE 示例，显式标注为测试内容，不是实际知识答案；未调用付费模型，不代表真实 LLM 的首字时延或答案质量。
- 固定姿态的世界坐标验证与页面交互测试分开记录；没有把几何单测当作完整页面点击测试。
- 未测硬件 GPU 功耗、长期显存变化、60fps 保证、手机真机、离屏/后台调度的全组合。无 WebGL 与减少动态效果首次加载有组件测试；浏览器本轮主要验证上下文丢失后的降级及偏好切换。
- 当前仍使用已有约 17.8MB 中文字体；未新增字体、模型或第三方依赖。未修改 API、配方 JSON、知识库及图谱。
- 档案载体没有知识数据绑定；编号只表示展示对象。

## 复现

先在 web 启动 `npm run dev -- --host 127.0.0.1`。运行 `node scripts/check_spatial_frontend.mjs <现有 playwright 包目录> output/frontend-spatial/recheck`。脚本仅启动本机 Edge headless、读本地页面并输出截图和 JSON，不安装浏览器或 npm 依赖。
