# 重要变更记录

本文只记录已经完成、仍影响当前行为的改进。未完成设计见 [EXTENSIBILITY.md](EXTENSIBILITY.md)，详细历史证据见 `archive/`。

## 2026-09-12：Web 共享空间与档案交互

- 将 Hero、滚动过渡区和 Query 纳入同一按需 Three.js 环境：官方角色与黄黑信息设计保留，双螺旋档案阵列贯穿页面；
- 开场改为约 6 秒的终端文字、轨道扫描、欢迎画面和退场节奏，8 秒安全超时，保留会话一次、跳过、重播与减少动态效果；
- 档案载体改为更宽薄的圆角玻璃结构，后处理目标使用最高 4x MSAA，并降低泛光以减少白边扩散；
- 新增中央主环与两条辅环；鼠标指针、阵列浏览和原生页面滚动驱动平滑圆弧运动，触摸端保持 `pan-y`，不劫持纵向滚动；
- 查询提交后立即显示真实阶段、不确定进度和等待秒数；档案抽取后隐藏就绪/跳过提示，避免覆盖结果；
- 保留模式草稿、缓存、请求取消、静态模式、WebGL 失败与上下文丢失降级；稳定阅读时停止渲染；
- 生产构建、42 项 Web 测试、10 项前端契约通过；1440×900 与 390×844 浏览器验收和边界见 [空间升级验收](FRONTEND_SPATIAL_ACCEPTANCE.md)。

## 2026-09-12：触摸滚动修正与验收工具入库

- 修复 `.helix-hitarea` 用 `touch-action: pan-x` 阻断纵向手势的问题：触摸端改为保持页面原生纵向滚动，阵列浏览交给 ↑↓ 按钮，鼠标拖动与拾取不受影响；
- `check_spatial_frontend.mjs` 纳入仓库并在 [工具与命令](TOOLS.md) 登记用法，浏览器验收证据可本地复跑（依赖已存在的 Playwright，不安装新依赖）；
- `check_docs.py` 跳过 `logs/`、`tmp/`、`output/` 等非项目文档目录，文档链接门禁不再扫描第三方参考稿。

## 2026-09-10：问答生命周期与双端一致性

- 流式问答在 ASGI 开始响应后才取得并发名额、扣除次数并创建 Trace，响应层与生成线程保证名额只释放一次；
- 配方数据、物品索引、代码版本和 KB 名称位置按进程缓存；KB 坏行安全跳过，无命中查询不再反复扫描全库；
- `chat_json` 只在上游明确不支持 JSON 格式参数时去参重试；评测拒答优先使用线上 `rejected` 字段；
- Web 模式切换不再提交草稿，增加停止生成，移除首 token 前的面板重挂载，流式结束后再解析 Markdown；
- 小程序修复干员语音来源、引用表格、KB link/行内图片代理，整包问答超时改为 180 秒；
- Nginx 为合成查询和媒体代理增加独立频率/连接限制，整包问答代理超时同步为 180 秒。

## 2026-09-09：Web 与小程序视觉统一

- Web 改为终末地官网风格的冷白、炭黑和高亮黄信息系统；桌面固定左轨，移动端紧凑顶栏；
- 动效收敛为单向遮罩和短反馈；开场缩至约 1.25 秒、每会话一次，并加 2 秒硬超时与减少动画降级；
- 使用本地归档的官方角色和地景素材，保存来源 URL、大小和 SHA256；
- 小程序同步黄黑视觉和关键素材，移除首页开场幕布与旧 Q 版装饰，保留触控优先交互。

## 2026-09-08：后端正确性、性能与安全整改

- 实体解析改为完整名称优先，修复“重息壤→息壤”“诀的信物→诀”，并保留真实来源 ID；
- 名称分词、规范化和向量 ID 映射改为加载期预计算，查询去重并避免已命中实体后的重复检索；
- 同机 warm 离线探针中，两类普通实体问题从约 796/813 ms 降至约 24/25 ms；该数字不含在线 LLM；
- 同来源多个 chunk 有界聚合，明确点名条目在最终 Top-K 中得到保护；整改后 71 条快照 Recall@5 100%、MRR 98.36%；
- RAG 增量更新删除缩短条目的遗留 chunk，模型变化隔离目录，BM25/manifest 原子发布，最终审计失败即失败；
- GraphRAG 增量指纹覆盖更多来源与规则，实体使用 UPSERT，查询库只读，路径来源可追溯；
- 流式响应严格检查完成原因，截断续写与重试共享 75 秒默认 LLM 操作预算；
- 媒体代理拒绝 SVG/HTML/未知 MIME，并加 CSP；CORS、synthesis 参数和问答准入顺序收紧。

## 2026-09-03：流式问答与完整性修复

- 新增 `/api/ask/stream`，Web 支持来源先亮和答案增量显示，旧 `/api/ask` 继续供小程序与评测；
- 流式与非流式共用上下文准备、拒答逻辑和完整结果；
- 生成预算提高至 1,600 tokens，长度截断最多续写一次；
- 长来源由 `focus_long_context()` 分散选取相关窗口，复合问题保护各子问题；
- 枚举由后端确定性返回完整清单；启动入口默认预热 embedding 和索引。

- 加入深度健康、进程指标、脱敏 Trace、反馈隔离审核、坏例回放和版本化评测清单；
